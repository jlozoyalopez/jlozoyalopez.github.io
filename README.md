# Mobile Ordering App — Test Case Management & Functional QA

## 📝 Project Overview
This project simulates the QA process of validating a mobile food-ordering application.  
The focus was on creating structured test cases, running functional test cycles, and documenting defects clearly.

## 🎯 Objectives
- Understand core user flows in a mobile ordering system  
- Create manual test cases aligned with requirements  
- Perform functional testing and identify UX/UI defects  
- Document findings using clear, reproducible steps  

## 🛠 Tech & Tools
- Google Sheets  
- Functional Testing  
- Test Case Design  
- Bug Reporting  
- Requirements Analysis
